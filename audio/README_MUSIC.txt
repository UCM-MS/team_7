BACKGROUND MUSIC SETUP

Put ONE audio file in this folder, using one of these exact names:
  background_music.ogg  (Ogg Vorbis)
  background_music.mp3
  background_music.wav

Do not simply rename an MP3 file to .ogg. The extension must match the actual audio format.
After copying the file, return to Godot and wait for the import process to finish. If it does not appear, use Project > Reload Current Project, then check the Audio tab in the Import dock.

Playback starts when ZAČAŤ HRU is clicked. It continues during level changes and other game screens. The Settings menu has a separate background-music ON/OFF switch. The player also prints a message to the Output panel when a track is loaded, or a warning when no supported track is found.

Use only an audio recording you are legally allowed to use. The copyrighted Lambada recording is not included.
